# Sprint 1 — Autenticação e Usuários

**Duração:** 2 semanas · **Módulos:** 01, 02, 03, 04

---

## Contexto

> **Paula (Scrum Master):** Bem-vinda ao time. Somos quatro: a Renata é a PO, o Marcelo é
> o dev, eu faço o processo rodar e você é a nossa QA. O produto é uma API de finanças
> pessoais que já está de pé — o time construiu a base e agora vamos evoluir módulo a
> módulo, com qualidade dessa vez.
>
> Esta sprint é de fundação. A Renata vai apresentar as stories de autenticação, você vai
> montar o Jira e o Qase, e vai preparar a coleção do Postman. Não vai ter build nova para
> testar — a autenticação já está em produção e é estável. Aproveite para conhecer o
> produto sem pressão.

**Tradução:** esta sprint é de aquecimento. Você monta as ferramentas e aprende a testar
uma API. **Não tem bug plantado.** Se você achar algum de verdade, melhor ainda.

---

## Objetivos

1. Ambiente rodando e Swagger acessível *(Módulo 00)*
2. Entender o que é QA de verdade *(Módulo 01)*
3. Participar do primeiro refinement *(Módulo 02)*
4. Jira e Qase configurados e integrados *(Módulo 03)*
5. Coleção Postman de autenticação com assertions *(Módulo 04)*

## Definition of Done da sprint

- [ ] Ambiente sobe do zero sem consulta
- [ ] Projeto Jira com workflow de bug completo e coluna In QA
- [ ] Projeto Qase com a árvore de suítes e integração com o Jira
- [ ] Stories cadastradas e alocadas na Sprint 1
- [ ] Coleção Postman com pelo menos 8 requisições, todas com assertion
- [ ] Collection Runner executado e resultado exportado
- [ ] Tudo commitado e enviado para o GitHub
